# Combinatorial coverage for BDD100K

This project studies how the choice of training images affects object detection under a fixed budget. It uses greedy maximization of a submodular coverage objective to select BDD100K images for Faster R-CNN.

- [Setup and experiment commands](bdd100k_faster_rcnn/README.md)
- [Research report](bdd100k_faster_rcnn/RESEARCH_REPORT.md)
- [Night evaluation](bdd100k_faster_rcnn/FINAL_EVALUATION_RESULTS.md) and [night-count control](bdd100k_faster_rcnn/NIGHT_COUNT_CONTROL_RESULTS.md)
- [Rain evaluation](bdd100k_faster_rcnn/RAIN_EXPERIMENT_RESULTS.md), [class analysis](bdd100k_faster_rcnn/RAIN_CLASS_ERROR_ANALYSIS.md), and [checkpoint comparison](bdd100k_faster_rcnn/RAIN_SEED42_CHECKPOINT_DIAGNOSTIC.md)
- [Presentation](bdd100k_faster_rcnn/professor_materials/out/BDD100K_Post_Midsem_Presentation.pdf) and [editable Beamer source](bdd100k_faster_rcnn/professor_materials/out/BDD100K_Post_Midsem_Presentation.tex)

The repository includes selection manifests and saved metric tables. To train or run inference, obtain the BDD100K images and labels separately and follow the setup guide for the expected directory layout. Model checkpoints are generated by the training scripts.
